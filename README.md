# AI Video Studio

A **free experimental prototype** that renders a narrated vertical 2+ minute English science-mystery MP4 using GitHub Actions, Pillow, FFmpeg, and offline espeak-ng. No paid API keys or PC uptime required for the cloud build.

## Run your first video
1. Open **Actions** in this repository.
2. Select **Build sample mystery video**.
3. Click **Run workflow**, choose `main`, and confirm.
4. Wait for a green success mark, open the run, and download the **mystery-video** artifact ZIP.
5. Unzip it to get `mystery.mp4`.

**Current limitations:** prototype is a narrated motion-slide video, not cinematic generative AI footage. Offline speech sounds synthetic. The script is currently fixed, and it does **not** generate 3 different videos daily or send notifications yet. Fact-check and review before publishing. GitHub Actions free usage depends on current GitHub policy and account limits. No Facebook auto-publishing.
